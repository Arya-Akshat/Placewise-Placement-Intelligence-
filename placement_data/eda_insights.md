# Exploratory Data Analysis Insights

The following observations were identified during exploratory analysis of the dataset:

1. Placement rates increase significantly for students with a CGPA above 8.0.
2. DSA problem-solving ability is strongly associated with salary outcomes.
3. Internship experience has a measurable impact on placement probability.
4. GitHub activity demonstrates a positive relationship with compensation.
5. Open source contributors tend to exhibit stronger technical profiles.
6. Tier-1 institutions consistently report the highest average salaries.
7. CSE, AIML, and IT branches outperform other disciplines in placement metrics.
8. Communication skills contribute significantly to employability.
9. Students with multiple projects generally receive better offers.
10. Competitive programming ratings are positively correlated with placement success.
11. Leadership experience contributes positively to placement outcomes.
12. Hackathon participation is common among highly placed students.
13. Certifications provide an advantage in placement readiness.
14. LinkedIn activity demonstrates moderate correlation with career engagement.
15. Attendance percentage alone is not a strong predictor of placement success.
16. Mechanical and Civil branches show comparatively lower placement rates.
17. The dataset includes realistic outlier profiles for advanced analysis.
18. Package distributions closely resemble expected engineering placement trends.
19. The dataset is suitable for both introductory and intermediate ML workflows.
20. Multiple feature combinations can be leveraged to derive employability scores.
