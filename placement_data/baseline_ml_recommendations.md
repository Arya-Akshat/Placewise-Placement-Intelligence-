# Baseline Machine Learning Recommendations

## Classification

### Objective

Predict whether a student will be placed.

### Suggested Models

* Logistic Regression
* Decision Tree
* Random Forest
* XGBoost
* CatBoost

### Suggested Metrics

* Accuracy
* Precision
* Recall
* F1 Score
* ROC-AUC

## Regression

### Objective

### Suggested Models

* Linear Regression
* Random Forest Regressor
* Gradient Boosting Regressor
* XGBoost Regressor

### Suggested Metrics

## Suggested Workflow

1. Handle missing values.
2. Encode categorical variables.
3. Scale numerical features.
4. Perform train-test splitting (80:20).
5. Train baseline models.
6. Evaluate performance.
7. Conduct feature importance analysis.
